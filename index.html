ERP Data Analyst Agent
Streamlit app that converts natural language questions into SQL using GPT-4o. Schema retrieval (RAG) embeds every table, ranks them against the question by cosine similarity, then expands along foreign keys so the model keeps the tables it needs to JOIN. Read-only validation blocks every write verb; results are auto-visualised and explained.
RAG LangChain GPT-4o Streamlit SQLAlchemy Python
Live demo → GitHub →
Polymarket Signal Analyser
An agentic pipeline that reads Polymarket prediction markets for equity signals: an LLM scores each market's relevance to a configurable stock watchlist, a tool-calling agent answers questions over the data, and the same tools are exposed through an MCP server. Built for the Google × Kaggle AI Agents capstone — with a pre-LLM guardrail and a 14-case eval harness.
LLM Agent MCP OpenAI Streamlit Supabase Python
Live demo → GitHub →
Semiconductor Validation Agent
GenAI tooling over a Postgres chip-validation database: turns written requirements into structured test plans, answers questions about test results in natural language, and generates reports with a mermaid requirement-traceability chain.
